# Suggested Features

- **Threshold alerts** — Notify users when CPU, memory, disk, battery, or process usage stays above a configured limit.
- **Metric history** — Show short-term CPU, memory, network, and load trends with compact sparklines.
- **Process detail view** — Inspect a selected process with its path, start time, memory, CPU, and thread information.
- **Process search and filtering** — Quickly find processes by name, PID, path, or resource usage.
- **Disk I/O monitoring** — Display read/write throughput and operation rates alongside disk capacity.
- **Filesystem overview** — Show usage for each mounted filesystem instead of only the root filesystem.
- **Network connection view** — List active connections, remote addresses, ports, and owning processes when available.
- **Container awareness** — Show effective CPU and memory limits when LoutreView runs inside a Linux container or cgroup.
- **Temperature monitoring** — Display available CPU, GPU, battery, and system temperature sensors.
- **Thermal throttling status** — Indicate when the system reports thermal or power-related throttling.
- **GPU monitoring** — Add GPU utilization, memory, temperature, and power metrics where native APIs support them.
- **Prometheus output** — Export current metrics in a format that existing monitoring systems can scrape.
- **Startup change detection** — Highlight startup services and login items that were added, removed, enabled, or disabled.
